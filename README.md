# ✈️ Tripulantes

Tripulantes es una aplicación web para elegir destinos turísticos de forma colaborativa y en tiempo real.

Las personas conectadas pueden votar, proponer nuevos destinos y observar cómo cambian los resultados sin recargar la página.

## Funciones

- Votación de destinos en tiempo real.
- Actualización automática para todos los usuarios.
- Propuesta de destinos nuevos.
- Barras y porcentajes de votos.
- Destino líder.
- Contador de personas conectadas.
- Actividad reciente.
- Reinicio de votación.
- Persistencia local de datos.
- API disponible en `/api/resumen`.

## Tecnologías

- Node.js
- Express
- Socket.io
- HTML, CSS y JavaScript
